# NutriMind AI 🍏

*Your Personal AI-Powered Nutrition & Wellness Companion.*

NutriMind AI is an elegant, feature-rich mobile application built with Flutter that helps users cultivate healthy eating habits, track hydration, analyze food items with Gemini AI, and plan delicious, goal-tailored meals. 

---

##  Key Features

* AI-powered nutrition coach for personalized guidance, meal suggestions, and nutrition advice.
* Smart food and label scanner that analyzes meals, estimates nutrition, and provides health ratings.
* Daily hydration tracker with interactive water intake logging.
* Curated recipe collections with favorites for quick access.
* Personal health profile with body metrics and customizable water reminders.
* Guided onboarding tour introducing the app's main features.
* Modern, responsive interface with smooth animations and Dark/Light mode support.
